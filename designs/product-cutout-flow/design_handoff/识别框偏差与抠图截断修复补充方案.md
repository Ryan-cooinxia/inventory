# 识别框偏差与抠图截断修复补充方案

## 现象

视觉模型返回：

```text
主商品：[446,102,800,800]
```

但原图中产品实际完整范围约为：

```text
[355,75,795,765]
```

最终结果缺失产品左侧五个按钮、部分机身和顶部区域。

## 根因

当前系统错误地把视觉大模型返回的 bbox 当作像素级硬裁剪边界。

视觉大模型擅长：

- 判断哪个对象是商品
- 判断文字、Logo 和背景的语义
- 给出大致位置

视觉大模型不擅长：

- 像素级精确边界
- 保证 bbox 完整包围所有细小结构
- 处理紧贴广告文字的商品边缘

当前后端还有两个放大问题：

1. `rembg_crop` 虽然临时扩展 5%，但 `_clean_target_mask()` 最后又按照原始错误 bbox 将扩展区域清零。
2. 排除框与商品框发生重叠，直接扣除排除 bbox 会切掉真实商品。

因此只调整 Prompt 无法彻底解决。

---

# 正确方案

将视觉模型 bbox 从“最终裁剪框”改成“商品定位种子框”：

```text
视觉模型语义识别
→ 生成近似 seed bbox
→ 自动扩大为 search bbox
→ 在 search bbox 中执行前景分割
→ 根据连通区域和商品种子点选择商品 mask
→ 从 mask 反推真实 tight bbox
→ 用户确认
→ 原图 RGB + mask
```

## 一、视觉识别结果增加语义种子

要求视觉模型除 bbox 外返回：

```json
{
  "main_product": {
    "bbox": [446, 102, 800, 800],
    "center_point": [620, 430],
    "positive_points": [
      [620, 430],
      [720, 650],
      [475, 260]
    ],
    "confidence": 0.99
  }
}
```

正向点应落在：

- 商品中心主体
- 商品下部主体
- 商品左侧易遗漏结构

视觉模型坐标仅作为定位提示，不作为最终边界。

## 二、自动扩大搜索框

新增：

```python
def expand_detection_bbox(bbox, image_size):
    pass
```

建议：

```python
pad_left = width * 0.30
pad_right = width * 0.08
pad_top = height * 0.12
pad_bottom = height * 0.05
```

或通用配置：

```python
SEARCH_BOX_EXPANSION = {
    "left": 0.30,
    "right": 0.12,
    "top": 0.15,
    "bottom": 0.08
}
```

对于当前框 `[446,102,800,800]`，搜索框应至少扩展到约：

```text
[340,20,800,800]
```

搜索框只是运行分割的区域，不能作为最终 Alpha 边界。

## 三、使用连通区域选择商品

在扩大后的 search bbox 中运行 rembg `only_mask=True`。

得到 mask 后：

1. 做连通区域标记。
2. 保留包含 `positive_points` 的区域。
3. 如果多个正向点命中不同但相邻区域，则合并。
4. 删除未命中正向点的广告文字和 Logo 区域。
5. 删除面积过小的孤立区域。

伪代码：

```python
labels, count = ndimage.label(binary_mask)

selected_labels = set()
for x, y in positive_points:
    label = labels[y, x]
    if label > 0:
        selected_labels.add(label)

if not selected_labels:
    # 回退：选择与 seed bbox 中心重叠最多的连通区域
    selected_labels.add(
        component_with_max_overlap(seed_bbox)
    )

product_mask = np.isin(labels, list(selected_labels))
```

这样即使搜索框包含左侧广告，广告通常属于其他连通区域，不会被保留。

## 四、从 mask 反推真实商品框

分割完成后计算非透明像素的真实边界：

```python
ys, xs = np.where(product_mask > 0)
tight_bbox = [
    int(xs.min()),
    int(ys.min()),
    int(xs.max()) + 1,
    int(ys.max()) + 1
]
```

数据库同时保存：

```json
{
  "detected_bbox": [446,102,800,800],
  "search_bbox": [340,20,800,800],
  "segmented_bbox": [360,82,790,760]
}
```

最终质量检查必须使用 `segmented_bbox`，不能继续使用视觉模型的 `detected_bbox`。

## 五、禁止使用原始 bbox 清除扩展区

当前 `_clean_target_mask()` 使用原始 keep bbox 将框外清零，会再次截断商品。

修改为：

- 初始分割阶段使用 `search_bbox`
- 清理阶段使用选中的连通区域 mask
- 最终只清除 `search_bbox` 外内容
- 不再使用原始 `detected_bbox` 作为 Alpha 硬边界

错误：

```python
mask_arr[outside_detected_bbox] = 0
```

正确：

```python
mask_arr[outside_search_bbox] = 0
mask_arr = keep_selected_components(mask_arr, positive_points)
```

## 六、排除框不能覆盖商品保护区

当前排除框：

```text
Feature bullets: [43,542,385,800]
```

而真实商品约从 `x=360` 开始，存在重叠。

直接将整个排除框设为透明会误删商品左下侧。

必须采用“商品保护优先”：

```python
safe_remove_mask = remove_mask & ~protected_product_mask
final_mask[safe_remove_mask] = 0
```

P0 阶段推荐：

- 排除框只用于语义提示和质量审核。
- 商品主体分割完成后，不再用粗排除 bbox 强制切割与商品 mask 重叠的区域。
- 只清除排除框中“不属于已选择商品连通区域”的像素。

伪代码：

```python
for remove_bbox in remove_targets:
    region = bbox_to_mask(remove_bbox)
    final_mask[region & ~product_component_mask] = 0
```

## 七、增加边界完整性自动检查

视觉模型识别框如果贴住商品或图片边缘，应自动判定有截断风险。

检查：

```python
def detection_bbox_needs_expansion(bbox, image_size):
    return (
        bbox touches image edge
        or foreground touches bbox edge
        or product key points lie near bbox edge
    )
```

分割后检查 mask 是否触碰 search bbox 边缘：

```python
touch_left = mask[:, 0].any()
touch_right = mask[:, -1].any()
touch_top = mask[0, :].any()
touch_bottom = mask[-1, :].any()
```

如果触碰搜索框边缘：

1. 自动扩大搜索框。
2. 重新分割。
3. 最多重试两次。
4. 仍触边则要求人工确认。

当前案例中右侧和底部触及原图边缘属于正常情况，但左侧与顶部不应触及搜索框边缘。

## 八、修复完整性评分

当前“目标框填充率”不能判断产品是否完整。

商品本来就不需要填满矩形框，因此：

```python
fill_ratio = foreground_area / bbox_area
```

不能作为主要完整性指标。

改用：

- mask 是否触及非图像边界的 search bbox
- positive points 是否全部位于最终 mask 内
- 视觉模型二次检查是否缺失主要部件
- segmented bbox 是否明显小于检测预期

质量结果增加：

```json
{
  "all_positive_points_covered": true,
  "mask_touches_search_left": false,
  "mask_touches_search_top": false,
  "bbox_expansion_retries": 1,
  "detected_bbox": [],
  "search_bbox": [],
  "segmented_bbox": []
}
```

以下情况不得通过：

- 任一关键正向点不在最终 mask 内
- mask 触碰可扩展方向的搜索框边界
- 左侧按钮、旋钮、屏幕或底部热靴缺失
- 自动扩框重试后仍无法确认完整性

## 九、前端展示

页面同时显示三种框：

- 黄色虚线：视觉模型近似框
- 青色虚线：自动扩大后的搜索框
- 绿色实线：分割 mask 反推的真实商品框

显示：

```text
视觉识别框：[446,102,800,800]
自动搜索框：[340,20,800,800]
实际商品框：[360,82,790,760]
自动扩框次数：1
关键点覆盖：3/3
```

用户可以直观看出视觉识别框并不是最终裁剪框。

## 十一、实施优先级

### P0

1. 视觉模型返回中心点与三个正向点。
2. bbox 自动扩大为 search bbox。
3. rembg 在 search bbox 中运行。
4. 使用正向点选择商品连通区域。
5. 不再用 detected bbox 硬裁。
6. 从 mask 反推 segmented bbox。
7. 排除框不得切割已选商品 mask。
8. mask 触边时自动扩框重试。
9. 用当前 XPro-C 图片验收。

### P1

将 rembg 连通区域选择替换为 SAM 2：

```text
search bbox + positive points + negative points → SAM 2 mask
```

视觉模型仍然只提供语义定位，不承担像素分割。
