# OZON 主视频采集增强 (2026-06-27)

## 策略升级

视频和富文本本质不同 — 视频是"点击后才生成的媒体资源"，不能按 DOM/Selection 思路处理。

三级采集策略：
- **P0**：视频入口信息（cover、duration、source_area、need_manual_check）
- **P1**：点击触发 + 嗅探真实 video src / m3u8 / mp4
- **P2**：m3u8 转 MP4、FFmpeg 转码（后续）

## 新增函数（content.js）

| 函数 | 作用 |
|------|------|
| `findOzonMainGallery()` | 定位商品主图区域，排除买家秀/评论区 |
| `extractVideoEntryFromGallery(gallery)` | 从主图 gallery 提取视频入口（video tag + 缩略图标记） |
| `extractOzonVideoUrlsFromRawText(rawText)` | 全页 raw text 正则扫描 mp4/m3u8 URL |
| `collectRawPageTextForVideo()` | 收集页面 HTML + script + window 变量供扫描 |
| `getPerformanceVideoResources()` | Performance API 嗅探已加载视频资源 |
| `dedupeVideoResults(list)` | 按 url/poster/source+duration 去重 |
| `scrapeOzonVideoByClick()` | 异步：点击 gallery 播放入口 → 等待 → 读 video.currentSrc → 读 performance 新增资源 |

## 视频合并策略（extractOzonProduct）

5 路来源合并，去重：

1. **DOM `<video>` 元素** + JSON regex → `videos` 数组
2. **主图 Gallery** → `extractVideoEntryFromGallery(galleryEl)`（cover + duration + video tag）
3. **SPLIT_STATE** → background.js MAIN world
4. **stateObjects JSON** → `extractOzonVideos()` 深搜
5. **兜底** → raw text 正则 + Performance API

## 安全护栏

- `findOzonMainGallery()` 不加 buyer media 区域视频
- `isBuyerMediaArea()` 过滤 `Фото и видео покупателей`、`Отзывы`、`Вопросы`
- 所有 video 提取入口都检查 `isBuyerMediaArea(el)`
- 点击只限 gallery 内的播放按钮，不扫描全页

## UI 变更

- 新增 **"🎬 采集视频"** 按钮（紫色，位于"自动抓取富文本"下方）
- 点后提示：真实地址 N 个 + 入口 N 个
- 无视频时提示"该商品可能没有视频"

## 采集结果结构

```json
[
  {
    "role": "main_video",
    "url": "https://...m3u8",    // 真实地址（可能为空）
    "poster": "https://...jpg",  // 封面
    "duration_text": "00:30",    // 时长文本
    "source_area": "main_gallery",
    "source": "video_after_click | performance_after_click | video_tag | video_entry | dom_scan | split_state | raw_text_regex | performance_resource",
    "need_manual_check": true
  }
]
```

## 验收标准
1. ✅ 有真实 URL → 保存 url + source
2. ✅ 无真实 URL → 保存 poster + duration_text + need_manual_check=true
3. ✅ 不采买家秀视频 → source_area 始终为 main_gallery/performance/raw_text
4. ✅ 不影响已有功能 → JS 语法验证通过 + Flask 启动正常
