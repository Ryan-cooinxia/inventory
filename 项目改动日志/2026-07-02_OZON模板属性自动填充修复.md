# 2026-07-02 OZON 模板属性自动填充修复

## 问题

"根据采集资料自动填写"把 OZON 模板属性、采集属性、媒体字段、富文本字段都当成普通属性字典匹配，导致：
- `Тип=Видоискатель` 误填到视频链接
- `Вес товара, г=270` 误填到商品数量
- 品牌/兼容品牌被错误纳入翻译流程

## 修复

### 1. 字段策略分类层
新增 `_ATTR_STRATEGY` 字典，按属性名分类：
| 策略 | 属性 | 处理方式 |
|------|------|----------|
| `proper_noun` | 品牌、型号、卖家代码、相机兼容性、零件号 | 可匹配但不翻译 |
| `media_video` | Ozon视频名称/链接/封面 | 从草稿视频媒体池取 |
| `rich_content` | 富内容JSON | 只读（于富文本中调整） |
| `hashtags` | #标签 | 从 draft.hashtags_ru 取 |
| `unit_quantity` | 计量单位中的商品数量 | 默认=1 |
| `weight` | 商品重量 | 从采集属性匹配 |
| `skip` | PDF、说明书 | 不自动填充 |
| `matchable` | 其他 | 正常匹配 |

### 2. 硬规则
- `_is_proper_noun()` — 纯英文值或已知品牌名不翻译、不标"未翻译"
- 重量字段只能匹配采集属性中的 `Вес товара, г`，不能匹配"数量"
- 视频字段只从 `draft.media_json.videos` 取，不从采集属性匹配

### 3. 前端改进
- 属性下拉：专有名词不标 ⚠️
- 富内容JSON：显示"（于富文本中调整）"
- 采集源属性左侧：中文字段名+中文值，专有名词保持原样

### 影响文件
- `blueprints/ozon.py` — `_ATTR_STRATEGY`、`_get_attr_strategy()`、`_is_proper_noun()`、`_fill_video_attr()`、重构 `api_draft_auto_fill_apply`
- `templates/ozon/listing_review.html` — 属性渲染逻辑
