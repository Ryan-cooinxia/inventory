## P0: 多模型候选图框架（已提交: 9de5201）

### 数据库
- 新增 `OzonImagePlan` — 图片方案表（plan_type: listing/aplus, target_language 等）
- 新增 `OzonImageReference` — 参考图关联表
- `OzonImageSlot` +10 字段: plan/buyer_question/main_claim/generation_mode/qa_required 等
- `OzonImageCandidate` +8 字段: parent_candidate/generation_mode/auto_qa_json/revision_count 等
- 安全 migration: `migrate_ozon_image_schema()` 逐列 ALTER TABLE + PRAGMA 检测

### 服务层
- `services/ecommerce_image_reference.py` — 按 slot role 自动选择参考图
- `services/image_generation.py` — 多 provider 生成（GPT Image/Seedream/Wanxiang/Banana）

### 路由
- `POST /ozon/image-candidate/<id>/select` — 选用候选图为最终图
- `POST /ozon/image-candidate/<id>/score` — 5 维度评分
- `GET /ozon/uploads/ai_generated/<path>` — 本地图片访问
- `/ozon/models` — 支持 save_image_gen action，provider 文本输入 + 快捷填充

### 模板
- `image_plan.html` — 候选图列表、评分表单、参考图标签、text_only 警告
- `models.html` — Provider 自由输入 + datalist + 快捷按钮

## P0.5: Seedream 4.5 联调修复（已提交: e41be59）

### Seedream 独立适配器
- 新增 `_call_seedream_api()` — 用 `requests` 直调 ARK API
- `image` 参数使用火山官方数组格式 `["url1", "url2"]`
- 请求体包含: `watermark: false`, `response_format: "url"`, `sequential_image_generation: "disabled"`
- 不发送 `n`, `output_format`, `guidance_scale`
- 预设尺寸: `default_size="2K"`, `portrait_size="2K"`

### API Key 修复
- 保存: `encrypt_api_key(api_key)` 加密存储
- 读取: `try decrypt except fallback to plaintext` 兼容旧明文 Key

### 俄语 Prompt 修复
- `build_slot_prompt()` 接受 `marketplace`/`language` 参数
- `LANGUAGE_RULES` 字典: ozon→Russian, amazon_us→English
- 删除硬编码 "use short English text only"，改为动态 f-string

### 参考图选择修复
- 不再限制 `for_ozon == True`，允许所有未 rejected 的源图
- SKU 槽位: SKU 对应图优先于通用 SKU/主图
- Package 槽位: 阻止主图冒充，返回空列表阻止 reference 模式

### 图片保存
- 根据 Content-Type 响应头判断格式
- 根据 magic bytes (PNG/JPG/WebP) 检测真实格式
- 文件名扩展名与真实格式一致

### 测试端点
- `POST /ozon/api/models/test-image-gen` — 展示脱敏请求体（不调用付费 API）

### 模板
- Notes placeholder: `{"size":"2K"}`
- Seedream 快捷填充模型名: `doubao-seedream-4-5-251128`
