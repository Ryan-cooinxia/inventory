# 富文本自动采集 + 适配工作台增强 (2026-06-27)

## 改动范围
- 浏览器插件：富文本自动抓取
- 适配工作台：富文本 4-tab 展示 + 视频素材展示

## 新增功能

### 1. 插件：自动抓取富文本按钮
**文件**: `browser-extension/content.js`

- 在结果面板新增 "🤖 自动抓取富文本" 按钮（蓝色，位于"📋 采集选中文本"按钮下方）
- 实现 `autoScrapeRichText()` 函数，流程：
  1. 点击"Перейти к описанию"按钮（如果存在）
  2. 滚动查找描述区域（`findDescriptionRootByAnchor()`）
  3. 兜底：viewport 扫描找到最大的文本块
  4. 程序化选中（`selection.selectNodeContents()`）
  5. 调用 `scrapeRichTextBySelection()` 采集
  6. 更新 `window.__ozonExtractedData.rich_text`
- 状态反馈：成功显示字数+图片数，失败提示用户手动框选
- `preloadOzonDetailSections()` 现在也会设置 `window.__ozonManualRichText`

### 2. 适配工作台：富文本 4-tab 展示
**文件**: `templates/ozon/adaptation_workspace.html`

- 预览 tab：通过 `{{ rich_text.html | safe }}` 渲染 HTML 预览
- 纯文本 tab：textarea 显示（增大到 8 行，8000 字符）
- HTML 源码 tab：`<pre><code>` 显示（15000 字符）
- 图片 tab：缩略图网格展示富文本内嵌图片（最多 30 张，超出显示+N）
- 图片点击放大查看（`showSourceImage()` 函数）
- 统计信息：已采集字数 + 图片数

### 3. 适配工作台：视频素材展示
**文件**: `templates/ozon/adaptation_workspace.html`

- 左栏新增 "🎬 源商品视频" 卡片
- 每个视频显示 poster 缩略图（或 🎬 占位符）
- 显示 media_id、source_url（截断到 60 字符）
- "🎬 标记入口" 按钮：标记视频供后续下载/录制追踪
- 后端路由 `POST /api/source-media/<id>/mark-video-entry` 记录标记时间

### 4. 后端：视频入口标记 API
**文件**: `blueprints/ozon.py`

- 新增路由 `api_mark_video_entry(media_id)` (POST)
- 更新 `raw_json` 字段添加 `video_entry_marked`, `video_entry_marked_at`, `video_entry_marked_by`
- 设置 `review_status='pending'`

### 5. 前端 JS 新增函数
- `showSourceImage(url)` — 全屏覆盖层查看大图（复用自 gallery）
- `markVideoEntry(mediaId)` — 调用后端标记视频入口

## 影响文件
- `browser-extension/content.js` — 新增 `autoScrapeRichText()` + 按钮 + 事件处理
- `templates/ozon/adaptation_workspace.html` — 富文本 4-tab + 视频卡片 + JS 函数
- `blueprints/ozon.py` — 新增 `api_mark_video_entry` 路由
