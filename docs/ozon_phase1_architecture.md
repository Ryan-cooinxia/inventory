# OZON 模块 — 阶段 1：信息架构和菜单结构

版本：v0.2
日期：2026-06-14
状态：已更新（新增适配工作台、事实库、类目字典、模型配置 4 个页面，共 13 个页面）

## 1. 页面清单

| 编号 | 页面名称 | 路由 | 说明 |
|------|---------|------|------|
| P1 | OZON 工作台 | `/ozon/dashboard` | 总览仪表盘，展示关键数字和快捷入口 |
| P2 | 平台接口 | `/ozon/accounts` | OZON 店铺 API 凭证管理 |
| P3 | 采集列表 | `/ozon/sources` | 查看所有采集商品，支持一键生成草稿 |
| P4 | 商品适配工作台 | `/ozon/adaptation/<source_id>` | 三栏布局：源商品 / 商品事实 / OZON 草稿，选择适配关系 |
| P5 | 商品事实库 | `/ozon/fact-library` | 查看和管理所有标准化商品事实 |
| P6 | 类目属性字典 | `/ozon/category-attributes` | OZON 类目树、属性字典、字段映射、缺口检查 |
| P7 | 模型接口配置 | `/ozon/models` | 主模型 + 视觉工具模型配置和测试 |
| P8 | 图片方案 | `/ozon/image-plan/<draft_id>` | 管理一个草稿的图片槽位、提示词和生成结果 |
| P9 | 刊登草稿列表 | `/ozon/listings` | 查看所有草稿，按状态筛选，进入审核 |
| P10 | 刊登草稿审核 | `/ozon/listings/<draft_id>` | 草稿详情：编辑、校验、审核通过、提交发布 |
| P11 | 发布任务 | `/ozon/publish-jobs` | 查看发布任务状态、请求/响应、失败重试 |
| P12 | 提示词库 | `/ozon/prompts` | 管理按品类的提示词模板和图片规则 |
| P13 | 定价规则 | `/ozon/pricing-rules` | 配置汇率、毛利率、广告预留、物流阶梯 |

共 **13 个页面**，覆盖 PRD 全部模块及新增的适配层、类目属性字典、视觉模型配置。

## 2. 菜单结构

在现有导航栏新增 **"OZON 运营"** 下拉菜单，位于"统计报表"之后。

```
导航栏
├── 产品管理
├── 客户管理
├── 供应商管理
├── 客户订单
├── 供应商订单 ▼
├── OZON 运营 ▼                    ← 新增
│   ├── 工作台                      → /ozon/dashboard
│   ├── 平台接口                    → /ozon/accounts
│   ├── 模型接口                    → /ozon/models
│   ├── ──────────
│   ├── 采集列表                    → /ozon/sources
│   ├── 商品适配                    → /ozon/adaptation (商品事实库作为内部 tab)
│   ├── 刊登草稿                    → /ozon/listings
│   ├── 发布任务                    → /ozon/publish-jobs
│   ├── ──────────
│   ├── 类目属性字典                 → /ozon/category-attributes
│   ├── 提示词库                    → /ozon/prompts
│   └── 定价规则                    → /ozon/pricing-rules
├── 统计报表 ▼
├── 客户资金总览
```

菜单分组逻辑：
- **总览区**：工作台、平台接口、模型接口（配置类，使用频率低）
- **操作区**：采集列表 → 商品适配 → 刊登草稿 → 发布任务（按工作流顺序排列）
- **配置区**：类目属性字典、提示词库、定价规则（基础配置，使用频率低）

## 4. 各页面主要操作

### P1 OZON 工作台

**路由**：`/ozon/dashboard`

**展示内容**：
- 统计卡片行：已配置店铺数、采集待处理数、草稿待审核数、可发布数、发布中数、发布失败数、已发布数
- 最近失败原因列表（最多 5 条）
- 快捷操作按钮：采集商品、查看待审核草稿

**主要操作**：
- 点击统计卡片跳转到对应列表
- 点击"采集商品"跳转到采集列表

**页面状态**：正常（有数据）、空态（首次使用，提示先配置店铺）

---

### P2 平台接口

**路由**：`/ozon/accounts`

**展示内容**：
- 店铺卡片列表（名称、类型、测试/正式标、最近同步时间、连通状态）
- 每个卡片上有：编辑、测试连通、删除按钮

**主要操作**：
- 新增店铺（弹窗或独立页面）：填写名称、选择跨境/本土、选择测试/正式、输入 Client-Id / Api-Key
- 测试连通性：点击后调用 `/v3/product/list` 验证
- 编辑店铺信息
- 删除店铺

**页面状态**：有店铺、空态

---

### P3 采集列表

**路由**：`/ozon/sources`

**展示内容**：
- 筛选栏：来源平台（1688/淘宝/天猫/拼多多/手动）、状态
- 表格列：来源平台标、商品标题、SKU 数、图片数、采集时间、状态、操作
- 操作按钮：查看详情、生成 OZON 草稿、删除

**主要操作**：
- 点击"进入适配" → 跳转到商品适配工作台
- 点击"查看详情" → 展开/弹窗显示采集 JSON 概要
- 手动粘贴采集 JSON 入库（按钮在页面顶部）

**页面状态**：有数据、空态（提示安装浏览器插件或手动粘贴）

---

### P4 商品适配工作台

**路由**：`/ozon/adaptation`、`/ozon/adaptation/<source_id>`

**展示内容**（三栏布局）：
- 左栏：源商品资料（来源平台、源链接、源标题、源 SKU、源图片、源属性、价格、供应商信息）
- 中栏：商品事实库（标准商品名、SKU 拆解、颜色、尺寸、款式、套装数量、包装内容、材质、功能、适配型号、尺寸重量、证据引用、置信度标记）
- 右栏：OZON Listing 草稿预览（适配策略、类目候选、属性映射、字段缺口清单）

**主要操作**：
- 选择适配关系（一对一 / 一对多 / 多对一）
- 手动编辑事实字段
- 锁定/解锁事实字段
- 标记低置信度字段
- 查看视觉识别结果
- 查看字段缺口检查结果
- 生成 OZON Listing 草稿

**页面状态**：正常、空态（提示先从采集列表进入）

---

### P5 商品事实库

**路由**：`/ozon/fact-library`

**展示内容**：
- 筛选栏：商品类型、审核状态、置信度
- 表格/卡片列表：标准商品名、商品类型、SKU 数、置信度、审核状态、证据数量
- 展开：完整事实字段、证据引用、未知字段

**主要操作**：
- 查看详情
- 编辑事实
- 审核通过/需修改
- 进入适配工作台

---

### P6 类目属性字典

**路由**：`/ozon/category-attributes`

**展示内容**：
- 本地品类与 OZON 类目对照表
- 类目属性列表：属性名、是否必填、数据类型、是否字典值
- 属性值字典（枚举值展开）
- 字段映射规则：本地字段路径 → 填充策略
- 字段缺口清单

**主要操作**：
- 拉取 OZON 类目树
- 拉取类目属性
- 拉取属性值字典
- 手动配置字段映射规则
- 查看字段缺口

---

### P7 模型接口配置

**路由**：`/ozon/models`

**展示内容**：
- 主模型配置区：Provider、Model Name、API Base、API Key
- 视觉模型配置区：Provider、Model Name、API Base、API Key、是否启用
- 测试图片上传区
- 测试结果展示区

**主要操作**：
- 配置/编辑主模型
- 配置/编辑视觉模型
- 上传测试图片
- 查看识别结果（OCR、主体识别、合规检查）

---

### P8 图片方案

**路由**：`/ozon/image-plan/<draft_id>`

**展示内容**：
- 视觉风格选择区（预设风格卡片：极简、科技、应急工具等）
- 图片槽位列表（每行一个槽位）：
  - 序号、角色（主图/SKU图/场景图/卖点图/功能图/细节图/尺寸图/包装图）
  - 适用范围（全部SKU 或 指定SKU）
  - 提示词（中/俄文，可编辑）
  - 负面提示词
  - 生成状态
  - 预览缩略图
- 底部按钮：生成图片、保存、返回草稿

**主要操作**：
- 选择视觉风格
- 编辑单个槽位的提示词
- 点击"生成图片"
- 审核每张图片（通过/拒绝）
- 查看大图

**页面状态**：空槽位（未规划）、已规划待生成、生成中、已生成待审核

---

### P9 刊登草稿列表

**路由**：`/ozon/listings`

**展示内容**：
- 筛选栏：状态（草稿/待审核/已就绪/已通过/发布中/已发布/失败）、客户/类目
- 表格列：商品标题（俄语）、源商品、SKU 数、状态标、审核状态、更新时间、操作
- 操作按钮：编辑审核、删除

**主要操作**：
- 点击"编辑审核" → 跳转到 P10
- 按状态筛选

**页面状态**：有数据、空态

---

### P10 刊登草稿审核

**路由**：`/ozon/listings/<draft_id>`

**展示内容**（分区域）：
- **信息区**：源商品链接、采集时间、源数据证据
- **内容区**：俄语标题、卖点、描述（可编辑），置信度标记
- **类目区**：OZON 类目路径、属性表（属性名、值、来源、置信度）
- **SKU 区**：SKU 列表（顺序号、名称、颜色、尺寸、价格），与源 SKU 顺序对比
- **图片区**：已审核图片缩略图，点击查看大图
- **定价区**：成本明细、建议售价 RUB、手动售价 RUB（可编辑）
- **校验区**：发布前校验结果（通过/阻断项列表）
- **操作区**：保存、发布前校验、审核通过、提交测试店发布

**主要操作**：
- 编辑任何字段
- 点击"发布前校验" → 展示阻断项
- 点击"审核通过" → 状态变为已通过
- 点击"提交测试店发布" → 调用 OZON API，跳转到 P11

**页面状态**：草稿、待审核、已通过、发布中、已发布、失败

---

### P11 发布任务

**路由**：`/ozon/publish-jobs`

**展示内容**：
- 筛选栏：状态（待处理/进行中/成功/失败）、店铺
- 表格列：任务 ID、店铺、草稿标题、操作类型、状态、创建时间
- 展开行：请求 JSON（折叠）、响应 JSON（折叠）、错误信息
- 操作按钮：重试（仅失败任务）

**主要操作**：
- 点击展开查看请求/响应详情
- 重试失败任务

**页面状态**：有数据、空态

---

### P12 提示词库

**路由**：`/ozon/prompts`

**展示内容**：
- 品类筛选下拉
- 提示词模板列表（卡片或表格）：
  - 名称、适用品类、类型（标题/卖点/描述/图片）、内容预览
- 展开后显示完整提示词 + 变量说明
- 内置规则文档链接：上架总原则、SKU主图规则、详情图规则、负面规则、质量验收规则

**主要操作**：
- 新增/编辑/删除提示词模板
- 查看规则文档

**页面状态**：有数据、空态（使用系统默认规则）

---

### P13 定价规则

**路由**：`/ozon/pricing-rules`

**展示内容**：
- 表单布局：
  - 汇率来源（手动/自动，当前汇率显示）
  - 目标毛利率（%）
  - 广告预留比例（%）
  - 佣金率（%）
  - 物流重量阶梯表（重量范围 → 运费 CNY）
  - 风险缓冲（CNY 固定值或 %）
- 实时预览：输入采购价 → 显示计算过程 → 显示建议 RUB 售价
- 保存按钮

**主要操作**：
- 编辑各项参数
- 实时预览计算
- 保存

**页面状态**：已配置、未配置（使用默认值）

## 5. 数据流概览

```text
[浏览器插件] → JSON
                   ↓
            ┌──────────┐
            │  P3 采集列表│ ← 手动粘贴 JSON
            └────┬─────┘
                 │ 进入适配
                 ▼
            ┌──────────┐    ┌──────────────┐
            │ P4 商品适配 │ ←─│ P7 模型接口   │ (视觉识别 + 主模型)
            │  (含事实库) │ ←─│ P6 类目字典   │ (字段缺口检查)
            └────┬─────┘    └──────────────┘
                 │
                 ▼
            ┌──────────┐
            │ P8 图片方案 │ ←── P12 提示词库
            └────┬─────┘
                 │
                 ▼
            ┌──────────┐
            │ P9 草稿列表 │
            └────┬─────┘
                 │ 审核
                 ▼
            ┌──────────┐
            │P10 草稿审核 │ ←── P13 定价规则
            └────┬─────┘
                 │ 提交发布
                 ▼
            ┌──────────┐
            │P11 发布任务 │ → OZON API
            └──────────┘
                 │ 回写
                 ▼
            [OZON 商品 ID / 状态]

配置层：
  P2 平台接口 ──→ 提供 API 凭证
  P6 类目字典 ──→ 提供字段映射和缺口检查
  P7 模型接口 ──→ 提供视觉识别 + 主模型推理
  P12 提示词库 ──→ 提供 AI prompt
  P13 定价规则 ──→ 提供价格计算公式
```

## 6. 与现有系统的关系

- OZON 模块不修改现有订单、库存、财务、客户功能。
- 使用现有 `base.html` 基模板和 Bootstrap 5 样式体系。
- 复用 `flask_login` 的 `@login_required` 和 `current_user` 隔离机制。
- OZON 数据表独立新增，不修改现有 models。
- 汇率可复用现有 `ExchangeRate` 表，或 OZON 模块独立配置来源。
