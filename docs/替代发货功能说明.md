# 替代发货功能

## 功能概述

客户订货后由于库存不足需要用其他产品替代交付时，通过发货页面的三个机制处理：
1. **替代品金额抵扣** — 实时显示替代品金额与订单剩余应发的差额
2. **取消剩余未发** — 未发完的从订货量扣除
3. **替代品独立订单** — 替代品自动生成新客户订单

## 入口

**订单列表 → 点击「发货」按钮**

## 发货页面操作

### 步骤

1. 在「订单产品明细」中填写本次发货数量
2. 在「额外添加产品（换货交付）」中添加替代产品、数量、单价
3. 查看蓝色提示框中的**抵扣计算**：
   ```
   订单剩余应发：¥5000
   替代品合计：¥5200
   差额：+200（客户需补）
   ```
   备注栏会自动填入差额信息
4. 确认底部两个开关
5. 点击「确认发货」

### 开关说明

| 开关 | 默认 | 勾选效果 | 不勾选效果 |
|---|---|---|---|
| 取消剩余未发 | ☑ | 未发完的量从订货量扣除 | 剩余保留，订单保持部分发货 |
| 替代品独立订单 | ☑ | 替代品生成新订单+自动发货 | 替代品附加到原订单 |

### 差额处理

- **替代品金额 = 剩余应发金额**：刚好抵扣，无需后续处理
- **替代品金额 > 剩余应发**：备注标记"客户需补 ¥X"，订单完成后向客户收款
- **替代品金额 < 剩余应发**：备注标记"需退客户 ¥X"，订单完成后退款

## 修正历史订单

订单列表中有发货记录但明细不匹配的订单（之前用替代品发的），会自动显示「**修正订货量**」按钮。

点击后将每行产品的订货量缩减到实际发货量，订单总额同步更新。

**触发条件**：有发货记录 + 存在某行产品 发货量 < 订货量

## 数据流

```
发货提交 →
  ├─ 正常产品出库（扣库存）
  ├─ 原订单剩余量取消（减少订货量）
  ├─ 替代品生成新订单 → 自动完成发货（扣库存）
  └─ 备注记录差额（客户补款或退款）
```
