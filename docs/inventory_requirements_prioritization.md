## 3. P0 立即修复

### 3.1 供应商采购单明细编辑/删除 bug

原需求：

> 在供货商采购单中，如果订单包含多个产品，对订单中的单个产品进行编辑时编辑页面是空的；删除单个产品时，发现整个订单被删除，而不是仅删除单个产品。

优先级：

```text
P0 立即修复
```

原因：

- 这是现有功能 bug。
- 可能误删整单，影响数据安全。
- 会直接影响采购、库存、财务记录。

实施方案：

1. 检查供应商订单相关路由。
2. 区分“删除整单”和“删除订单明细”两个操作。
3. 单个产品编辑应以 `SupplierOrderItem.id` 为主键。
4. 删除单个产品时只删除 `SupplierOrderItem`，不删除 `SupplierOrder`。
5. 删除后重新计算供应商订单总金额。
6. 如果订单明细删空，再提示是否删除整单，不自动删除。

验收标准：

- 一个供应商订单有 3 个产品时，编辑第 2 个产品能正确显示该明细。
- 删除第 2 个产品后，订单仍存在，剩余 2 个产品仍存在。
- 订单总金额自动更新。
- 操作日志记录“删除供应商订单明细”，不是“删除供应商订单”。

给 Claude Code 的任务：

```text
请优先修复供应商订单明细编辑/删除 bug。
要求：单个明细编辑和删除必须基于 SupplierOrderItem.id，不得误删 SupplierOrder。
完成后补充手动验证步骤，不要改无关功能。
```

## 4. P1 第一阶段：成本、资金、套装

### 4.1 厂家降价和供应商价补

原需求：

> 由于厂家产品价格变化，导致之前高价订的货价格下跌了，然后供应商价补，这部分价格变化如何表现在订单及金额上。

优先级：

```text
P1 必须做
```

业务解释：

供应商价补不应该简单改历史采购单价格。历史采购单代表当时交易事实，价补应该作为一笔后续调整记录。

建议模型：

```text
SupplierAdjustment 供应商调账/价补
```

调整类型：

```text
price_compensation   降价价补
quality_refund       质量退款
shortage_refund      缺货退款
manual_adjustment    手工调整
```

字段建议：

```text
供应商
关联供应商订单
关联订单明细，可为空
产品，可为空
调整日期
调整类型
调整金额
影响方向：供应商欠我 / 我欠供应商
是否影响库存成本
备注
附件/截图
用户
创建时间
```

财务处理建议：

分两种模式：

1. **不改历史成本，只作为供应商余额抵扣**
   - 适合已经销售或成本已确认的货。
   - 报表显示为“供应商价补收益”。

2. **影响库存成本**
   - 适合库存仍在手里，需要降低库存成本。
   - 需要按剩余库存或指定批次调整成本。

第一版建议：

```text
先做供应商余额抵扣，不直接重算历史库存成本。
```

验收标准：

- 可对某个供应商订单录入价补。
- 价补金额进入供应商资金余额。
- 报表能显示本期价补金额。
- 原采购单价格不被覆盖。

给 Claude Code 的任务：

```text

第一版不要修改历史采购单单价，只新增 SupplierAdjustment 记录，并计入供应商资金余额和报表。
```

### 4.3 套装型产品处理

原需求：

> 对于套装型产品在产品列表以及下单、客户分开供货的时候如何处理？如云台的套装。

优先级：

```text
P1 必须做
```

现状判断：

系统已有 `ProductBundle` 和 `ProductBundleItem` 的基础概念，但需要补齐实际业务流。

核心问题：

- 套装是虚拟商品还是实际库存商品？
- 下单时卖的是套装，出库时扣哪些单品？
- 客户分开供货时如何记录部分发货？
- 套装成本如何计算？

建议规则：

1. 套装本身作为“虚拟销售商品”。
2. 套装不直接拥有库存。
3. 套装库存 = 所有组件可组成的最小套数。
4. 客户下单套装时，订单显示套装。
5. 出库时按组件扣库存。
6. 允许部分组件分开发货。
7. 套装成本 = 组件成本 * 数量之和。

页面改造：

- 产品列表增加“单品/套装”标识。
- 产品详情显示套装组成。
- 下单选择套装时自动展开组件。
- 出库单支持按组件发货。
- 报表显示套装销售收入和组件成本。

验收标准：

- 可创建一个云台套装。
- 下客户订单时可选择套装。
- 出库时能看到套装组件。
- 支持部分组件先发、部分后发。
- 毛利按组件成本计算。

给 Claude Code 的任务：

```text
请完善套装商品业务流程。
要求套装作为虚拟销售商品，库存由组件计算，出库按组件扣减，并支持客户订单中的套装分开发货。
```
