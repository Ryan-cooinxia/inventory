# OZON 卖家沟通规则知识库

> 来源：https://global-help.ozon.com/zh/policies/product-rules-and-documents?region=CHN
> 更新日期：2026-06-20

---

## 一、不允许的行为

以下行为可能导致 **隐藏聊天消息、禁用与买家的沟通、或封禁卖家账号**：

| 序号 | 违规行为 | 说明 |
|---|---|---|
| 1 | **粗俗/侮辱性言语** | 使用粗俗词汇或侮辱性言语，以及涉及性别、种族、国籍、职业、社会类别、年龄、个人和公民语言、官方国家标志等可能会对 Ozon 商业声誉产生负面影响的隐晦词语、图像、比喻和表述 |
| 2 | **违法信息** | 提供违反俄罗斯联邦法律或第三方权利的信息 |
| 3 | **无礼态度** | 对买家的无礼态度和不道德行为 |
| 4 | **侮辱竞争对手** | 使用侮辱竞争对手及其商品的比喻或表述，利用涉及他人商品、作品、服务质量的信息 |
| 5 | **负面陈述** | 关于 Ozon、商品、作品、服务、人员、组织、其他 Ozon 卖家品牌的负面陈述 |
| 6 | **交换联系方式** | 与买家交换个人联系方式并提议使用其他通讯方式 |
| 7 | **建议取消订单** | 建议买家取消订单 |
| 8 | **收集个人数据** | 收集、复制、存储、分发或以任何其他方式使用买家的某些个人数据 |
| 9 | **不准确信息** | 向买家提供有关商品、作品、服务的不准确信息 |
| 10 | **误导买家** | 在商品、作品、服务的消费特性方面误导买家 |
| 11 | **宣传第三方** | 在 Ozon 上宣传和提及第三方资源、组织和其他 Ozon 卖家，包括指向 Ozon 以外的外部资源链接、地址、电话号码等 |

## 二、客服沟通规范

| 序号 | 规范要求 | 详细说明 |
|---|---|---|
| 1 | **商务风格** | 坚持商务风格的沟通方式。礼貌和尊重是商业通信和良好销售的基础 |
| 2 | **语言规范** | 请尽量使用通顺规范的语言。若对自身的表达用语不自信，网上有许多免费的快速文本检查服务 |
| 3 | **积极情绪** | 请表露积极的情绪。可喜的理由有很多，例如买家下了订单、留下了好评或获得了折扣。但如若事情不妥，最好不要扩散负面情绪，而要设法弄清情况并提供帮助 |
| 4 | **合规信息** | 请提供仅符合卖家合同条款、客户要约（包括知识库）和消费者权益保护法的信息。若合同或客户要约中规定了与法律不同的程序，则以该文件中指出的条件为准 |
| 5 | **不要求取消** | 请不要让买家取消订单。"卖家要求"这一取消原因会导致取消百分比增加，并且您将被收取处理此订单的额外服务费用，并导致聊天窗口的无限期封锁。如果订单无法完成，请在个人中心自行取消订单 |
| 6 | **格式规范** | 避免使用大写文本、过多的标点符号和表情符号 |

## 三、在线直播中的沟通规范

| 序号 | 规范要求 |
|---|---|
| 1 | 请尽量使用通顺规范的语言 |
| 2 | 请仅提供符合俄罗斯联邦法律（包括广告法和消费者权益保护法在内）的最新可靠资讯 |
| 3 | 请根据使用说明（如有）提供有关商品技术特性的信息 |
| 4 | **请勿使用最高级描述商品**，例如"最好的"、"最方便的"、"排名 No.1 的商品"、"我们的价格最低"、"品种最多"等均不可取，除第三方已进行相关研究并证实描述准确无误的情况外 |
| 5 | 请勿分心或同时进行多个对话 |
| 6 | 请尽可能礼貌、妥当和友好地进行沟通 |
| 7 | 尊重买家的决定，在言语中请避免强制性语气 |

## 四、对我们系统 AI 内容生成的影响

以下规则需要在 AI 生成俄语商品描述时遵守：

| 规则 | 影响 | AI Prompt 注意事项 |
|---|---|---|
| 禁止最高级描述 | AI 生成的卖点/描述中不能使用"лучший"、"самый"等最高级形容词 | Prompt 中明确禁止最高级用词 |
| 禁止不准确信息 | AI 描述必须基于真实商品属性，不能编造功能或参数 | Prompt 中要求基于采集数据生成 |
| 禁止宣传第三方 | 描述中不能包含外部链接、其他平台名称（如淘宝、1688） | Prompt 中要求过滤中国平台信息 |
| 禁止负面对比 | 不能在描述中贬低竞品 | Prompt 中禁止对比性描述 |
| 合规信息 | 描述需符合俄罗斯联邦法律 | 需了解俄罗斯广告法基本要求 |
